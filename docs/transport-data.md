# 東京都の交通データ取得

交通種別ごとのデータソース、取得方法、カラム定義は以下を参照してください。

- [鉄道データ](transport-data/railway.md) — 国土数値情報 N02、東京メトロ ODPT、JR東日本の扱い
- [路線バスデータ](transport-data/bus.md) — 都営・民営バスの GTFS/GTFS-JP、ODPT API

## 共通方針

- **地理形状を伴う鉄道路線**は国土数値情報（N02）を基礎データにする。
- **バス**は ODPT の GTFS/GTFS-JP を優先する。
- ODPT のアクセストークンは環境変数で管理し、フロントエンドへ露出させない。
- 公開時は各データセットの利用規約・クレジット表記を確認する。
